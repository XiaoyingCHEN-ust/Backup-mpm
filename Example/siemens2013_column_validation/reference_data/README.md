# Experimental reference data

The CSV files are derived from Siemens et al. (2013), *Water Resources
Research*, 49, 851–863, <https://doi.org/10.1002/wrcr.20101>.

- `wetting_front_open.csv` is an approximate reading of the coarse open-test
  wetting-front trajectory in Figures 6a and 11a.
- `wetting_front_closed.csv` is an approximate reading of the coarse
  closed-test trajectory in Figures 8a and 11a.
- `closed_air_pressure_envelope.csv` records the 1.2–1.6 kPa range stated in
  Section 4.2 for all six pore-pressure transducers after the first 25 s.

The front locations were digitised from plotted curves because pointwise
tabulated measurements were not published. They should be treated as plotting
targets with figure-reading uncertainty, not as exact raw data. The pressure
range is a directly reported experimental target and was not used to calibrate
the numerical input.
